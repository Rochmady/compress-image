# Compress Image

Compress Image adalah aplikasi web sumber terbuka yang memungkinkan Anda mengompres gambar secara efisien tanpa mengurangi kualitas secara signifikan. Aplikasi ini dirancang untuk memudahkan pengguna dalam mengurangi ukuran file gambar untuk kebutuhan web, pengiriman email, atau penyimpanan.
🌐 Tautan Aplikasi

👉 https://apps.sangia.org/tools/compress/compress_image
📌 Fitur Utama

    🚀 Pengompresan Cepat: Kompres gambar dalam hitungan detik.

    🖼️ Dukungan Format Luas: Mendukung format JPEG, PNG, dan lainnya.

    📁 Pengunggahan Ganda: Kompres beberapa gambar sekaligus.

    🔒 Privasi Terjaga: Semua proses dilakukan di sisi klien; gambar Anda tidak diunggah ke server.

    🎯 Antarmuka Sederhana: Desain intuitif yang mudah digunakan oleh siapa saja.

🛠️ Cara Menggunakan

    Unggah Gambar: Klik tombol "Pilih Gambar" dan pilih gambar dari perangkat Anda.

    Kompres Gambar: Setelah gambar terunggah, proses kompresi akan berjalan otomatis.

    Unduh Gambar: Setelah proses selesai, klik tombol "Unduh" untuk menyimpan gambar yang telah dikompres.

📷 Contoh Penggunaan

💡 Teknologi yang Digunakan

    HTML5 dan CSS3: Untuk struktur dan desain antarmuka pengguna.

    JavaScript: Untuk logika aplikasi dan proses kompresi gambar.

    Canvas API: Untuk memproses dan mengompres gambar di sisi klien.
